# Compare three MPNN model families

Run ProteinMPNN, LigandMPNN, and SolubleMPNN on the same bundled cortisol
complex. Each branch uses the public LigandMPNN implementation with its
corresponding checkpoint and produces packed structure rows. The standard
handler API combines the branches while retaining their input and model lineage.

```bash
chaperone install ligandmpnn
python examples/benchmarks/multi-mpnn/pipeline.py --test --local --rundir=/absolute/path/mpnn-smoke
```

`--test` requests one sequence per model (three total); the default requests
four per model. MPNN runs on CPU by default. Use `--local` where the required
hardware is already allocated, or omit it to submit through Slurm.

For AF3 refolding, install `alphafold3`, configure separately obtained
`ALPHAFOLD3_WEIGHTS_DIR`, and add `--refold`. Each branch uses one AF3 sample
and its own prediction and RMSD steps. The illustrative selection gates are
AF3 ranking score ≥0.5 and backbone RMSD ≤3 Å, measured for that branch.
These gates assess fold recovery; they do not establish cortisol binding.

The ligand is cortisol, CCD `HCY`, with 26 heavy atoms. AF3 receives the
explicit isomeric SMILES from the cortisol example so the prediction uses the
intended chemistry. AF3 assigns its own ligand atom names. LigandMPNN uses
ligand atoms during sequence design; ProteinMPNN and SolubleMPNN do not.
Their shared side-chain packing stage can still use ligand context.

Each sequence produces one packed structure (`output_mode="structures"`,
`number_of_packs_per_design=1`). Distinct filename suffixes and separate AF3
steps prevent branches from overwriting each other's inputs. The merged
handler is unpacked and repacked to check row and design-ID preservation.
Outputs are ordinary engine artifacts plus `results.csv` in the run directory.
Without `--refold`, sequence design and packing are the endpoint. With
refolding, an empty result means no candidate met the illustrative gates.

## Fixture provenance and validation

`files/cortisol_complex.cif` contains the 151-residue protein and cortisol from
the first packed design of the cortisol smoke campaign on 2026-10-17:
`refine/cycle_0/mpnn/chunk_0/fixed/cortisol_chunk0_cortisol_0_model_0__0_1.pdb`.
The CIF preserves those coordinates and adds CCD-derived bond definitions.
The parent backbone was generated by RFD3 and its sequence and sidechains by
LigandMPNN. This is a computational fixture, not an experimental structure.

Its subsequent AF3 prediction had minimum interaction PAE 5.79 and three
H-bonds, so it failed the cortisol campaign's cycling gate. Reusing the
structure here tests sequence-design mechanics and does not promote it as a
passing binder. The three-family benchmark has not been rerun on GPU with
this replacement fixture. CPU regression checks cover chemistry, independent
branch naming, and handler lineage; native PLIP checks run when its optional
dependencies are installed.
